# Videos de las lecciones

Archivos MP4 (H.264 + AAC, 720p recomendado) servidos por GitHub Pages. Nombre sin espacios ni tildes: `curso-mX.mp4` (un video por módulo) o `curso-mX-lY.mp4` (uno por lección).

| Archivo | Curso | Módulo |
|---|---|---|
| `montaje-smart-tv-m1.mp4` | Montaje Profesional de Smart TVs | 1 · Fundamentos y Herramientas |
| `montaje-smart-tv-m2.mp4` | Montaje Profesional de Smart TVs | 2 · Soportes y Mampostería |

Para usar uno en una lección: Admin → Lecciones → Editar → campo Video → `video/nombre.mp4`.
Límite práctico: GitHub acepta archivos de hasta 100 MB; para videos largos usa YouTube (no listado) y pega el enlace.
